# S5 — Implementation

Purpose: implement the approved Plan in atomic, verifiable steps.

For every step:

1. read relevant current code;
2. edit only approved scope;
3. run the smallest useful check;
4. update progress and actual impact;
5. write a checkpoint.

Forbidden:

- silent Plan changes;
- unrelated refactors;
- automatic dependency expansion;
- commit/push/deploy without applicable authorization.

Plan invalidation routes to S4. Spec ambiguity routes to S3.
