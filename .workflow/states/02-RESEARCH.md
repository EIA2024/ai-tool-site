# S2 — Read-Only Research

Purpose: establish verified project facts before specification.

Allowed:

- search/read files;
- inspect Git and configuration;
- run non-destructive read-only commands;
- trace call and data flows.

Required output:

- relevant files;
- current behavior;
- existing patterns;
- commands/environment;
- risks and unknowns;
- evidence.

Forbidden:

- business-code modification;
- unsupported assumptions;
- unlimited exploration.

Exit when blocking unknowns are resolved or explicitly escalated.
